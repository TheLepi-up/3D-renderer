Some implementation notes.

Renderer:
if position changed or rotation changed
  skip
for every pixel in shadowmap:
  If shadowmap does not contain pixel: raycast
  add squrare to multiset and shadowmap
reset shadowmap
for every squrare in multiset (closest to most distant):
  for every pixel in squrare
    if pixel was already rendered:
      skip to next empty pixel using shadowmap
      continue
    render pixel
  add square to shadowmap


Shadowmap:
  point-line comparison:
    Check if point P is right or on line A, B
    (P - A) * (rotateRight(B-A)) >= 0
  next point after line:
    
    t = (P.y-A.y) / (B.y-A.y)
    P.x = A.x + t * (B.x - A.x)

Project pixel on plane:
A, B: line
P, N: point on plane and normal
I: Intersection point
U = B-A
dot = U * N
W = A - P
fac = - N * W / dot
V = U * fac
I = A + V

noise:
  chunk: 16x16x16
  bounds contain points where spaghetti are joined together:
    coordinate (vec2) and direction (normalized vec3)
  inside the chunk: 
    connect matching points with splines and modify the splines with perlin noise
  matching points to avoid loops that are disconnected from the rest of the structure:
    identify every connection with a number and direction, there must be at least one output, so just add one to every side.
    inputs of numbers less than max-1 are connected to the smallest available output with a number bigger than the input
    inputs that are unused join into outputs that are already used, fill up from the lowest number.
    outputs that are unused join to each other starting by joining the highest with the lowest.
    every connection gives a spline. 
  distortion:
    rasterize all splines with a linear decay around each spline line.
    add perlin noise
    apply threshhold to get spaghetti.
